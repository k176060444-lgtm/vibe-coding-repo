# Readiness Receipts

This directory holds **read-only G-READINESS receipt YAML files**
generated by `scripts/create_readiness_receipt.py`.

Each receipt documents a point-in-time PASS/BLOCKED verdict on the
following 7 verification gates:

1. NMC exists and parses
2. `operator_approved` exact set = 6 entries (deepseek-v4-pro ×3 + mimo-v2-5 ×3)
3. qwen3-7-plus × 3 all `unknown`
4. Stage4 / Stage7 / apply-tool / G-L4 planning / D-B policy lock all pass
5. git working tree clean
6. open PRs = 0
7. `base_sha` matches current HEAD

A PASS verdict means all gates passed at the moment of generation.
A PASS receipt does **NOT** authorize gray promotion, Baseline03 entry,
or Stage8 entry — each subsequent gate requires a separate operator
authorization.

Receipts are produced by `scripts/create_readiness_receipt.py` and are
**not** generated as part of PR #356 (which only adds the generator and
its tests). The first real receipt will be generated under a separate
operator-authorized PR.

Receipt file naming: `readiness-receipt-<YYYYMMDD-HHMMSS>.yaml`
